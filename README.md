# 손가락 마우스 (FingerMouse)

카메라 앞 공중에서 **검지 끝**을 따라 포인터가 움직이고, **엄지+검지를 붙이면** 클릭(누른 채 움직이면 드래그)되는 안드로이드 앱입니다.
MediaPipe Hand Landmarker + CameraX 사용.

## APK 받는 방법 (GitHub)
1. 새 저장소를 만들고 이 폴더의 내용을 전부 올립니다 (`.github` 폴더 포함).
2. `main` 브랜치에 올라가면 **Actions** 탭에서 `Build APK`가 자동 실행됩니다 (약 5~8분).
3. 끝나면 저장소의 **Releases**에서 `app-debug.apk`를 폰으로 내려받아 설치합니다.
   (설치 시 "출처를 알 수 없는 앱" 허용 필요)

## 사용법
- 손을 폰 카메라 30~60cm 앞에 두세요. 오른쪽 위 미니맵에 손이 보이면 인식 중입니다.
- 노란 사각형 = 화면 전체로 매핑되는 손 움직임 범위. 슬라이더로 조절합니다.
- 화면의 [클릭 테스트] 버튼, [드래그] 상자, 슬라이더로 동작을 확인하세요.

## 전체 화면 모드 (다른 앱/화면에서도 사용)
1. 앱 아래의 [▶ 다른 화면에서도 사용] 버튼을 누르면 접근성 설정이 열립니다.
2. 설치된 앱(다운로드한 앱)에서 **손가락 마우스**를 켭니다.
   - Android 13 이상에서 켜기가 막혀 있으면: 설정 → 앱 → 손가락 마우스 → ⋮ → **제한된 설정 허용** 후 다시 시도
3. 앱으로 돌아와 같은 버튼을 다시 누르면 앱이 뒤로 가고, 모든 화면 위에 포인터와 버튼 줄(◀ 뒤로 / ● 홈 / ▣ 최근 / ■ 정지)이 뜹니다.
4. 엄지+검지 붙였다 떼기 = 탭, 오래 붙이고 있기 = 길게 누르기, 붙인 채 움직였다 떼기 = 드래그(스크롤/스와이프).
   드래그는 **놓는 순간** 같은 경로와 속도로 한 번에 실행됩니다.
5. 끝내려면 버튼 줄의 [■ 정지], 알림의 [정지], 또는 앱을 다시 여세요.

## 튜닝 포인트 (MainActivity.kt)
- 클릭 민감도(붙임/놓음 기준)는 앱 아래쪽 슬라이더로 조절하며 저장됩니다. 기본값은 `DEF_PINCH_ON` / `DEF_PINCH_OFF`
- `OneEuroFilter(1.5f, 0.02f)`: 앞 값을 낮추면 떨림↓(반응 느림), 뒤 값을 높이면 빠른 움직임에서 지연↓
